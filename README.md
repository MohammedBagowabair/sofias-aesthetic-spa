# Sofia's Aesthetic Spa

Marketing site for Sofia's Aesthetic Spa. Booking goes to WhatsApp at +65 8766 6949. There is no shop, payment, or database.

## Run locally

```bash
cd sofia
npm install
npm run dev -- --port 3927 --hostname 0.0.0.0
```

Open http://127.0.0.1:3927

## Build

```bash
npm run build
```

The static site is written to `out/`.
